Panel de administración

Entra con un token de acceso de GitHub. Solo funcionan los tokens de cuentas con permiso de escritura en CrissyjuanxD/Viciont-Studios-Portafolio.

¿Cómo consigo mi token? (1 minuto)
  1. Abre GitHub → Fine-grained tokens → Generate new token con tu cuenta.
  2. Token name: Panel Viciont · Expiration: la que prefieras (por ejemplo 1 año).
  3. Repository access: Only select repositories → Viciont-Studios-Portafolio.
  4. Permissions → Repository permissions → Contents: Read and write. No actives nada más.
  5. Pulsa Generate token, copia el código (empieza por github_pat_) y pégalo aquí.

Guárdalo como una contraseña. Si lo pierdes o crees que alguien lo vio, bórralo en GitHub y crea otro.
